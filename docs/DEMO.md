# Demo script

About 3 minutes. Rehearse until it's boring (task P3-ALL-3).

## Setup
- One laptop with everything running (`scripts/start.sh`, once it exists). The browser is on the HDMI screen.
- **Airplane mode on before you start**, and visibly so.
- A synthetic learner and passages are already loaded. The backup video is open in a second tab.

## Run
1. **Hook (20 s):** the 30-second pitch from the team deck.
2. **Airplane mode:** show Wi-Fi off and leave it off.
3. **Basa:** a teammate reads the Filipino passage with **two planted mistakes** (skip "ng", say "pala" for "palay"). Both get flagged. The teacher taps one to show the human check, then confirms. Reading speed and level appear.
4. **Another language:** repeat with the regional passage a teammate speaks. Line: *"No reading tool supports this language, and it still works."*
5. **Sanay:** open the learner's practice set. "palay" plays in the fluent speaker's voice, the reader says it and gets it right, and the progress panel updates.
6. **Class view:** groups by level and a draft plan per group.
7. **Close:** "No internet. Children's voices never left this laptop."

## Rules
- Invite a judge to read only if everything so far went smoothly.
- If anything breaks, switch to the backup video without apologizing at length.
- Never use real children's names or voices.
